# Top10QB graphic assets

`editorial-stadium-texture.png` is an original AI-generated background used behind the exact,
code-rendered weekly graphics.

It was generated from the Canva screenshots only as visual-direction references. The prompt asked
for:

- A near-black editorial sports background
- Restrained burnt-orange and deep-violet light
- Fine diagonal pinstripes, paper grain, and a soft vignette
- Faint scoreboard-like geometry
- No text, numbers, logos, people, players, footballs, team marks, border, or watermark

Names, dates, ranks, movement arrows, and takes are not part of this image. They are rendered from
the live published list by `/graphics/list`, which keeps the weekly graphics accurate and editable.
